Banking Policy Question Answering using RAG with Citations is an AI-powered system designed to simplify access to complex banking policy documents. Unlike traditional keyword-based searches, it understands user queries and retrieves relevant information using semantic search. By combining document embeddings, FAISS, and Large Language Models, it generates meaningful answers based on uploaded banking documents. Each response includes source references, enabling users to verify the information and build trust in the results. The main objective is to make banking information retrieval faster, smarter, and more transparent.
